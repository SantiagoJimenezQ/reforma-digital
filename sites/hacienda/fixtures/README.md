# Páginas de prueba

HTML **real** de las páginas públicas, capturado el 27‑09‑2026 con `npm run site:live` sin identificarse. Al capturarlo se eliminan `<script>`, `<noscript>` e `<iframe>`, se vacían los `<input type="hidden">` y se quitan los `;jsessionid`. No contienen datos personales, cookies ni sesiones.

`routes.json` indica qué fichero sirve el laboratorio local (`npm run dev`) para cada ruta oficial; lo usan las pruebas de `tests/e2e`.
